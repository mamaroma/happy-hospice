# Пансионат «Счастье» — сайт

Элегантный сайт-визитка пансионата для пожилых людей в светлых тонах.

## Структура

```
pansionat/
├── index.html              ← главная страница
├── sverdlovskaya.html      ← страница «Счастье на Свердловской»
├── bugri.html              ← страница «Счастье в Буграх»
└── assets/
    ├── css/style.css       ← стили
    ├── js/script.js        ← скрипты (мобильное меню + lightbox)
    └── img/
        ├── logo.jpg                  ← логотип в шапке
        ├── bugri/                    ← фото пансионата в Буграх (bugri-01.jpg … bugri-10.jpg)
        ├── sverdlovskaya/            ← фото пансионата на Свердловской
        └── leaders/                  ← сюда положить фото руководителей
```

## Как открыть сайт

**Вариант 1.** Двойной клик по `index.html` — откроется в браузере.

**Вариант 2.** Через локальный сервер (рекомендуется):

```bash
cd /Users/arsenij/Desktop/pansionat
python3 -m http.server 8000
```

Затем открыть в браузере: <http://localhost:8000>

## Как заменить плейсхолдеры на фото руководителей

Когда пришлёте фото:

1. Положите фотографии в папку `assets/img/leaders/`, например:
   - `assets/img/leaders/tatyana.jpg`
   - `assets/img/leaders/konstantin.jpg`

2. В файле `index.html` найдите блок `<!-- LEADERS -->` и замените два места:

   **Татьяна** — было:
   ```html
   <div class="leader-photo">
       <span class="leader-photo-placeholder">Т</span>
   </div>
   ```
   Стало:
   ```html
   <div class="leader-photo">
       <img src="assets/img/leaders/tatyana.jpg" alt="Татьяна">
   </div>
   ```

   **Константин** — аналогично, замените букву «К» на `<img src="assets/img/leaders/konstantin.jpg" alt="Константин">`.
